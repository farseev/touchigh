Social Media Algorithm: Bagong Controls ng Facebook, Ranking ng Instagram

Hinahayaan na ng Facebook ang mga user na kausapin ang algorithm nito at sabihin kung ano ang gusto nilang dumami o mabawasan. Ganito dapat mag-adjust ang mga brand para manatili sa feed ng audience nila.

Patuloy na nagbabago ang social media algorithm — paano ko iaangkop ang strategy ko para talagang gumanda ang reach ko?

Maikling sagotSa pinakaubod nito, hinuhulaan ng social media algorithm kung gaano kainteresado ang bawat user sa bawat post. Hinahayaan na ngayon ng Facebook ang mga user na direktang sabihin dito, sa pang-araw-araw na salita, kung ano ang gusto nilang dumami o mabawasan, at agad na umiiral ang pagbabago sa Feed at Reels. Dapat buuin ng mga brand ang bawat post sa paligid ng isang topic na mismong ang audience ang magsasabi, sabihin ito sa simula, at i-track ang shares, saves at comments, hindi lang likes.

Mahahalagang punto

  • Iniulat ng Social Media Today na nagdagdag ang Facebook ng plain-language controls sa feature nitong "Your Algorithm," para masabi ng mga user sa sarili nilang salita kung ano ang gusto nilang makitang mas marami o mas kaunti.
  • Umiiral ang bagong controls sa parehong Facebook Feed at Reels, at agad na nagkakabisa ang mga pagbabago.
  • Pagkatapos i-tap ng user ang "Interested" o "Not interested," maaaring magtanong ang Facebook ng follow-up, kaya mas nagiging tiyak ang negatibong feedback.
  • Walang iisang social media algorithm: kanya-kanyang nagra-rank ang bawat placement, kaya puwedeng ibang-iba ang performance ng parehong post sa Feed, Reels at Stories.
  • Ang pinakamahusay na paraan para paliitin ng brand ang information gap ay alamin, mula sa comments at direct messages, ang mga salitang ginagamit ng audience nito para ilarawan ang kanilang interes.

Patuloy na nagbabago ang social media algorithm, kaya paano dapat mag-adjust ang isang brand? Magsimula sa bahaging hindi nagbabago: sa Facebook at Instagram, iisang bagay ang hinuhulaan ng algorithm — magiging interesado ba ang taong ito sa post na ito? Nakakakuha ng reach ang content na malinaw na tumutugma sa isang interes. Ang pinakabagong pagbabago ay kaya na ng mga user na sabihin sa algorithm kung ano ang interes nila, nang direkta at sa sarili nilang salita.

Iniulat ng Social Media Today na nagdagdag ang Facebook ng plain-language controls sa dati nitong opsyong "Your Algorithm." Puwedeng i-type ng mga user, sa pang-araw-araw na salita, kung ano ang gusto nilang makitang mas marami o mas kaunti. Gumagana ito sa parehong Feed at Reels, at agad na nagkakabisa ang mga pagbabago. Inilalarawan ito ng Facebook bilang pagbubukas ng algorithm na talagang makakausap mo.

Ano ba talaga ang nagbago sa bagong algorithm controls ng Facebook?

Sa orihinal na "Your Algorithm," puwedeng magdagdag o mag-alis ang user ng topic mula sa listahan ng interes na hinuha ng system tungkol sa kanila. Nagdaragdag ang bagong bersyon ng prompt na parang chatbot kung saan basta na lang tina-type ng user ang paglalarawan ng content na gusto nila.

Ang ikalawang pagbabago ay ang follow-up questions. Ayon sa ulat, pagkatapos i-tap ng user ang "Interested" o "Not interested" sa isang post, maaaring magtanong pa ang Facebook ng ilang tanong para maipaliwanag ng user, sa sarili nilang salita, kung ano ang gusto nilang dumami o mabawasan. Sabi rin ng Meta, nag-a-adjust ang system sa loob ng parehong session para ipakita kung ano ang mahalaga sa user sa sandaling iyon.

Binanggit din ng Social Media Today na bihirang baguhin ng karamihan ng user ang settings nila, kaya hindi pa alam ang totoong epekto nito. Pero malinaw ang direksyon: lalong aasa ang mga algorithm sa interes na tahasang sinasabi ng user, hindi lang sa clicks at oras na ginugol.

Paano nagra-rank ng post ang social media algorithm? Facebook at Instagram, kada placement

Hindi iisang system ang "algorithm." Ibang problema ang nilulutas ng bawat placement, kaya ibang signal ang batayan ng ranking ng bawat isa. Pangkalahatang overview ang table sa ibaba para matulungan kang magpasya kung ano ang ipo-post saan:

Simple ang pattern. Habang mas nagrerekomenda ang isang placement ng content sa mga estranghero, mas nakadepende ito sa kung malinaw na tumutok ang content mismo sa isang interes. Habang mas nagsisilbi ito sa kasalukuyang followers, mas nakadepende ito sa relasyon mo sa kanila. Ilagay ang parehong post sa maling placement at puwedeng magkalayong-magkalayo ang resulta.

Bakit laging pakiramdam ng mga brand na hindi nila maintindihan ang algorithm?

Tinatawag ito ng mga ekonomista na information asymmetry: mas marami ang alam ng isang panig ng transaksyon kaysa sa kabila. Nakikita ng platform ang kilos ng bawat user; iilang numero lang sa sarili nitong dashboard ang nakikita ng brand. Alam ng user kung ano ang gusto nilang makita; nanghuhula lang ang brand. Habang lumalaki ang agwat, mas madaling ibuhos ang budget at pagsisikap sa maling content.

Medyo pinapaliit ng bagong controls ng Facebook ang agwat na iyon. Hindi na lang nakatago sa clicks at oras na ginugol ang interes ng user — isinusulat na ito sa salita. Pero nananatili sa platform ang data na iyon, at hindi ito nakikita ng mga brand. Ang kaya ng brand ay matutong unawain ang audience nito sa sarili nitong mga channel. Iyan ang pangunahing ideya ng article na ito: ang pag-unawa ang pundasyon ng koneksyon.

Isang hypothetical na halimbawa: laging binubuo ng isang handmade soap brand sa Hong Kong ang mga post nito sa paligid ng "natural ingredients." Matapos lang suyurin ang mga comment nito, napansin nito na karamihan ng tanong ng customer ay "OK ba ito sa sensitive skin?" at "Puwede ko ba itong gamitin sa baby ko?" Nang ilipat nito ang topic mula sa gustong sabihin ng brand ("natural") patungo sa talagang sinasabi ng audience ("bath time para sa sensitive skin"), sa wakas ay tumugma na ang content nito sa interes ng mga tao.

Paano maaapektuhan ng algorithm na makakausap ang reach ng brand?

Tatlong bagay ang makatwirang asahan. Una, ang mga interes na kayang isalita ng user ay kadalasang tiyak na topic, gaya ng "mas maraming home organization tips" o "mas kaunting post na parang ad." Mahirap ilagay sa alinman sa mga ito ang malabong content.

Ikalawa, mas mapanganib ang hard-sell na content. Kapag tahasang sinabi ng user kung ano ang ayaw nilang makita, agad na nag-a-adjust ang system, kaya mas malamang na masala ang engagement bait at clickbait na headline.

Ikatlo, may kalamangan ang mga account na consistent ang tema. Kung pagkain ang post ng page mo ngayon, kasalukuyang balita bukas at giveaway sa makalawa, hindi masasabi ng algorithm o ng audience mo kung saang interes ka nabibilang.

Mas mahalaga pa ito para sa mga brand mula Hong Kong at Taiwan na naghahandang magbenta sa US. Sa English ilalarawan ng mga American user ang interes nila, kaya kailangang tukuyin ang mga topic mo gamit ang mga salita nila. Sa halip na direktang isalin ang mga Chinese product category mo, tingnan muna kung paano inilalarawan ng mga US customer ang parehong bagay sa review at comment.

Paano ko iaangkop ang social strategy ko para gumana para sa akin ang algorithm?

  1. Tukuyin ang tatlong topic na talagang sasabihin ng audience mo. Gamitin ang salita ng customer, hindi marketing jargon: "small-apartment storage," hindi "space solutions."
  2. Sabihin ang topic sa simula ng bawat post. Sa unang tatlong segundo ng video o unang linya ng caption, gawing malinaw kung tungkol saan ang post.
  3. Ibalot sa kapaki-pakinabang na content ang sales message. Mas hindi nilalaktawan ang mga produktong ipinakilala sa tutorial, paghahambing at FAQ kaysa sa isinisigaw na promo.
  4. Idisenyo nang magkahiwalay ang Feed at Reels. Isulat ang Feed post para sa mga suki; isulat ang Reels para sa mga taong hindi ka pa kilala.
  5. Basahin ang comments at direct messages (DMs) isang beses kada linggo. Itala ang eksaktong salitang ginagamit ng mga tao para ilarawan ang pangangailangan nila, at gawin itong topic ng post sa susunod na linggo.
  6. I-track ang shares, saves at full views. Mas malinaw na senyales ang mga aksyong ito ng "gusto kong makakita pa" kaysa sa likes.
  7. I-test ito sa sarili mong account. Kung mayroon nang feature ang personal Facebook mo, sabihin sa algorithm na gusto mo ng content mula sa industriya mo, saka bantayan kung lumalabas ang mga post mo at ng mga kakumpitensya mo — at anong uri.

Aling mga mito tungkol sa algorithm ang puwede mo nang bitawan?

  • "May perpektong oras para mag-post": Mahalaga ang timing, pero mas mahalaga kung tumutok ang content sa isang interes. Tingnan muna ang sarili mong analytics bago magtiwala sa generic na schedule mula sa internet.
  • "Mas marami ang hashtag, mas mabuti": Mas mahalaga ang malinaw na topic kaysa sa dami ng tag.
  • "Kapag bumaba ang reach, tine-throttle ako": Tingnan muna kung lumabo ang mga topic mo o nagbago ang interes ng audience mo, saka gumawa ng konklusyon.
  • "Kapag nagbago ang algorithm, kailangan kong magsimula ulit": Nananatiling totoo sa bawat update ang pagtutok sa malinaw na topic, pag-aalok ng kapaki-pakinabang na content at taos-pusong pagsagot sa audience mo.
Insight
Ang pag-unawa ang pundasyon ng koneksyon.

Dahil sa information asymmetry, mas marami ang alam ng platform at ng mga user nito kaysa sa brand. Hinahayaan na ngayon ng Facebook ang mga user na isalita ang interes nila; kung matututunan ng brand ang parehong wika mula sa comments at DMs nito, maitutugma ng content nito ang mga topic na hinahanap ng algorithm.

FAQ

Ano ang plain-language algorithm controls ng Facebook?

Bagong bersyon ito ng feature ng Facebook na "Your Algorithm." Ayon sa Social Media Today, puwedeng sabihin ng user sa system, sa pang-araw-araw na salita, kung ano ang gusto nilang makitang mas marami o mas kaunti; umiiral ito sa Feed at Reels at agad na nagkakabisa. Pagkatapos i-tap ang "Interested" o "Not interested," maaari ring makatanggap ang user ng follow-up questions. Hindi sinasabi ng ulat kung aling mga rehiyon ang makakakuha nito o kailan.

Pareho ba ang algorithm ng Facebook at Instagram?

Hindi — at kahit sa iisang platform, kanya-kanyang nagra-rank ang bawat placement. Sa pangkalahatan, tinitimbang ng mga placement na nagrerekomenda ng content sa estranghero, gaya ng Reels, kung tumutugma ang content mismo sa isang malinaw na interes. Tinitimbang naman ng mga placement na nagsisilbi sa kasalukuyang followers, gaya ng Stories, ang relasyon mo sa nanonood. Kaya puwedeng ibang-iba ang performance ng parehong post depende sa kung saan ito lumalabas.

Biglang bumaba ang reach ko. Tine-throttle ba ako?

Hindi naman tiyak. Tingnan muna ang tatlong bagay: kung lumabo ang mga topic mo kamakailan, kung masyadong mukhang ad ang mga post mo, at kung nagbago ang interes ng audience mo. Ngayong tahasan nang nasasabi ng mga user ng Facebook kung ano ang ayaw nilang makita, mas madaling masala ang hard-sell na post at clickbait. Pagkatapos i-adjust ang mga topic at format, bantayan ang resulta sa loob ng dalawa hanggang apat na linggo bago magpasya.

Laging nagbabago ang algorithm. Gaano kadalas dapat i-update ng brand ang strategy nito?

Bihirang kailanganing baguhin ang pangunahing strategy mo: tumutok sa malinaw na topic, mag-alok ng kapaki-pakinabang na content at makipag-engage sa audience mo — nananatili ang mga prinsipyong iyon sa bawat update. Basahin ang comments at direct messages linggu-linggo, i-review ang shares, saves at full views buwan-buwan, at baguhin lang ang halo ng format o placement kapag nagpapakita ang data ng tuloy-tuloy na pagbabago.
