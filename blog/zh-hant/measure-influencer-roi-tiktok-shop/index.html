小品牌如何衡量 TikTok Shop 網紅行銷 ROI

大多數收到免費樣品的創作者從不發文，單支影片也很少能帶來銷售。這裡有一張簡單的計分表，讓您衡量 TikTok Shop 創作者 ROI 而不自欺欺人。

這篇文章回答的問題

我要如何準確衡量 TikTok Shop 上的網紅合作是否划算？

一句話回答按創作者衡量 TikTok Shop 的網紅 ROI，而不是按活動衡量。追蹤收到樣品的創作者中有多少人發文、每人做了幾支影片、每支影片的銷售額，以及包含免費產品、運費、佣金和費用在內的總成本。ROI 是歸因毛利減去這些成本，再除以成本。然後加上光環訊號，例如 Amazon 或網站銷售的提升，以及留言中的購買問題。

要點速覽

  • TikTok Shop 的網紅 ROI 應該按創作者衡量，因為銷售往往來自發布大量影片的創作者，而不是一次性的送樣。
  • Digiday 報導的一項 Flywheel 分析研究了 150 萬份 TikTok Shop 樣品，發現創作者只有 47% 的情況會發布影片，只有 14% 帶來銷售。
  • 在同一份分析中，發布 20 支以上影片的創作者，每支影片平均銷售額為 74.07 美元，而只發一次的創作者為 7.19 美元。
  • 真正的 ROI 計算要納入免費產品、運費、佣金和固定費用，並使用毛利而不是總銷售額。
  • 對於需要深思熟慮的購買，要追蹤光環效應：Whisker 預期它在 TikTok Shop 上的曝光會提升自家網站和 Amazon 上的銷售。

如何衡量 TikTok Shop 的網紅行銷 ROI？

逐一按創作者衡量，而不是按活動衡量。針對每位創作者，追蹤他們是否發文、做了幾支影片、這些影片帶來的銷售，以及他們花了您多少成本，包括免費產品。再加上幾個銷售報表遺漏的訊號，例如其他管道的銷售提升，以及大家在留言中提出的問題。

最新數據說明了為什麼按創作者看很重要。Digiday 本週報導了 Omnicom 旗下 Flywheel 利用 Reacher 數據所做的分析，研究對象是品牌寄給 TikTok Shop 創作者的 150 萬份產品樣品。大多數樣品從未變成影片，大多數影片也從未帶來銷售。與此同時，Modern Retail 描述了 Whisker 如何在不大幅打折的情況下，在 TikTok Shop 上銷售售價 699 美元的 Litter Robot，以及它為什麼在應用程式之外評判成效。

TikTok Shop 的新數據對創作者有什麼發現？

根據 Digiday 對 Flywheel 分析的整理，創作者收到樣品後只有 47% 的情況會發布影片，只有 14% 帶來任何銷售。如果您一直寄出免費產品，並把「觸及的創作者數」當作成功，這些數字應該會讓您心頭一緊。

更重要的發現與每位創作者的影片數量有關。只發一支影片的創作者，每支影片平均帶來 7.19 美元的銷售。發布 20 支以上影片的創作者，每支影片平均 74.07 美元，總計至少 1,481 美元。分析也顯示，較小的創作者每 1,000 位追蹤者帶來的商品交易總額（GMV，售出商品的總價值）可能高於較大的創作者，不過報導只以圖表呈現，沒有給出確切數字。

Flywheel 的建議很實際：一開始廣泛寄送樣品，再逐步聚焦到長期、可重複的合作關係。優先選擇較小的創作者，並按每筆銷售給他們分潤，鼓勵他們發布多支影片。對表現最好的創作者，在佣金之外再給固定費用或績效獎金。

哪些指標能看出某位創作者值不值得？

在一張表中追蹤這七個數字，每位創作者一列。投資報酬率（ROI）放在清單中間而不是最後，因為它周圍的指標能解釋它為什麼高或低。

指標計算方式它告訴您什麼
發文率發文的創作者數除以寄出的樣品數您的創作者名單和合作說明是否有效
每位創作者的影片數影片總數除以發文的創作者數投入程度；在 Flywheel 的數據中，反覆發文的創作者每支影片的銷售額高得多
每支影片的銷售額歸因 GMV 除以影片數內容和創作者與您產品的契合程度
每位創作者的成本產品成本 + 運費 + 佣金 + 任何固定費用或獎金每段合作關係的真實價格，而不只是佣金
創作者 ROI（歸因銷售的毛利減去每位創作者的成本）除以每位創作者的成本要保留、加碼還是放棄這位創作者

如何一步步計算創作者 ROI？

  1. 寄出前先登記每位創作者。記錄姓名、追蹤人數、寄樣日期、產品成本、運費、佣金比例，以及您們約定的任何費用。
  2. 設定固定的評估期間。例如從樣品送達起算 30 天，讓每位創作者都按同一個時間標準評判。
  3. 擷取每位創作者的歸因訂單和 GMV：在期間結束時，從 TikTok Shop 聯盟行銷報表中取得。
  4. 把 GMV 換算成毛利。扣除商品成本和平台費用。銷售額不等於利潤，靠折扣衝出來的高峰，GMV 看起來很漂亮，實際卻可能在賠錢。
  5. 扣除所有創作者成本，再除以這些成本。這就是您的創作者 ROI。
  6. 檢查光環效應。把期間內的品牌搜尋量、網站銷售和 Amazon 銷售，與之前一段類似的期間比較。
  7. 排序並採取行動。給表現最好的創作者獎金或更長期的合約，重新向中段的創作者說明合作要求，並停止寄樣給從不發文的創作者。

以下是一個假設的例子。一個小型保養品牌寄出 40 份樣品，每份產品加運費 13 美元，共 520 美元。創作者帶來 3,000 美元的歸因銷售。15% 的佣金是 450 美元，一位表現突出的創作者另得 200 美元獎金。扣除費用後毛利率為 60%，毛利就是 1,800 美元。創作者總成本為 1,170 美元，所以 ROI 是（1,800 美元減 1,170 美元）除以 1,170 美元，約 54%。把同一張表按創作者排序，每位創作者的數據就會清楚顯示是誰賺到了這些錢。

為什麼只看銷售數字會誤導人？

管理學中有一個概念叫績效衡量理論。白話說：您選擇關注的數字，會塑造您做出的決定。選錯了，您就會很有信心地朝錯誤的方向優化。

如果您只計算影片上線當週的 TikTok Shop 銷售，就會不斷獎勵折扣帶來的高峰，並淘汰那些建立需求、但成果在之後或其他地方才出現的創作者。這就是本文背後的洞察：衡量人心，而不只是數字。像「兩隻貓也能用嗎？」這樣的留言，以及品牌搜尋量的上升，都是真實興趣的早期訊號，甚至在訂單出現之前就看得到。

Whisker 示範了實務上的做法。Modern Retail 報導，該公司堅守 699 美元的價格而不打折，並緩慢擴大聯盟行銷計畫，偏好利基創作者，而不是大量發文的做法。行銷長 Hew Loyd 稱產品的自動清潔示範是「讓拇指停下來的畫面」。Whisker 預期它在 TikTok Shop 上的曝光會帶動自家網站和 Amazon 上的銷售，並希望把 TikTok Shop 的買家引進 Litter Robot 應用程式，以取得第一方數據。報導沒有公布任何銷售數字。對小品牌來說，教訓在於 Whisker 計算的是什麼，而不在某個數字。

Whisker 的做法看起來和 Flywheel 的建議不同，但兩者在核心觀點上一致：一次性送樣很少划算。對於衝動型的快速購買，許多小創作者反覆發布的影片可能是引擎。對於需要深思熟慮的產品，契合度和示範可能比觸及更重要。

小品牌的創作者計畫該做哪些調整？

別再用單支影片評判創作者。第一個月廣泛送樣，再把預算集中在少數反覆發文且有銷售的人身上。先付佣金，等創作者證明了自己，再加上獎金。

也要改進合作說明。一段在前幾秒就回答買家最大疑慮的示範，能讓每位創作者都有更好的起點。挑選這個鉤子的一種方法，是在向任何人說明需求之前先為概念打分。使用 ToucHigh 的社群和廣告自動駕駛，每個概念在上線前都會針對預測點擊率和互動評分。這是根據內容模式做出的上線前參考指標，不是保證，但它能幫您挑選要提供給創作者的示範角度，而不是靠猜。

核心洞察
衡量人心，而不只是數字。

績效衡量理論指出，您挑選的指標會塑造您做出的決定。只計算當週銷售，會獎勵折扣高峰；加入反覆發文、留言意圖和光環銷售，才能看出哪些創作者真正在建立需求。

常見問題

TikTok Shop 網紅行銷多少 ROI 算好？

沒有可靠的通用數字，已發布的基準也常混用不同的成本定義。不如設定您自己的底線：在評估期間內，創作者的歸因毛利至少要能涵蓋您在他身上花的產品、運費、佣金和費用。跨過這條線、又持續發文的創作者，值得加碼。從不發文的創作者，應該從名單上移除。

評判創作者表現前該等多久？

給每位創作者同樣固定的期間，例如從樣品送達起算 30 天，比較才公平。單支影片很少能說明什麼。Digiday 報導的 Flywheel TikTok Shop 分析發現，發布 20 支以上影片的創作者，每支影片平均銷售 74.07 美元，只發一支的則是 7.19 美元。要根據多支影片的整體模式來判斷。

該付創作者固定費用還是佣金？

對 TikTok Shop 上的大多數小品牌來說，先付佣金是比較安全的預設做法，因為只有在有銷售時才付錢。Flywheel 的分析建議優先與較小的創作者合作，按每筆銷售分潤以鼓勵他們發布多支影片，再對已證明實力的頂尖創作者額外給予固定費用或績效獎金。對還沒測試過的創作者，避免預付大筆費用。

如何衡量創作者對 Amazon 或我自己網站的影響？

把創作者推廣期間這些管道的銷售，與之前一段類似期間比較，並在 Google Search Console 中觀察品牌搜尋量。在結帳時加入一題「您是怎麼知道我們的？」問卷。Modern Retail 報導，Litter Robot 的製造商 Whisker 預期它在 TikTok Shop 上的曝光會帶動自家網站和 Amazon 上的銷售。
