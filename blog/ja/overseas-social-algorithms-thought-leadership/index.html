SNSのアルゴリズムが評価するもの：中国ブランドのためのソートリーダーシップ

アルゴリズムが評価するのはトレンドの追随ではなく、独自性と本物のエンゲージメントです。InstagramとFacebookの最新の変更をもとに、海外展開する中国ブランドがソートリーダーシップを築く方法を解説します。

この記事が答える質問

InstagramとFacebookはアルゴリズムを変え続けており、海外市場での当社ブランドの投稿はほとんどリーチがありません。最新の変更について何を知っておくべきですか？

短い答えSNSのアルゴリズムが評価するのは、模倣したトレンドではなく、独自性、新しさ、本物のエンゲージメントです。Instagram責任者のAdam Mosseri氏によると、ランキングは人々がどう反応するかの予測に基づいており、オリジナルのコンテンツは転載より上位に表示され、新しい投稿ほど多く表示されます。Facebookでは、ユーザーがもっと見たいものを平易な言葉でアルゴリズムに伝えられるようになりました。海外展開する中国ブランドにとって最も確実なのは、トライアルリールで少しずつ試しながら、専門家としてのソートリーダーシップを発信することです。

要点

  • Social Media Todayによると、Instagram責任者のAdam Mosseri氏は、ランキングは最後まで見るか、友だちに投稿をシェアするかなど、人々がどう反応するかの予測に基づいていると述べました。
  • Mosseri氏のランキングの原則には、オリジナルのコンテンツを優先すること、新しい投稿を優遇すること、小規模なクリエイターにも表示の機会を与えることが含まれます。また、再生回数やいいねではなく、エンゲージメント率を見るよう勧めています。
  • Facebookでは、ユーザーがフィードとリールで、もっと見たいもの・減らしたいものを日常の言葉でアルゴリズムに伝えられるようになり、おすすめは同じセッション内で調整されます。
  • トレンドの追随は典型的な群集行動です。誰のコンテンツも似てくるほど、アルゴリズムにもユーザーにも、個々の投稿を見分けにくくなります。
  • 海外展開する中国ブランドのソートリーダーシップは、型どおりのトレンド形式ではなく、ものづくりの知識、創業者の見解、製造の舞台裏、実際の顧客の質問を中心に据えるべきです。

最近、SNSのアルゴリズムでは何が変わったのか。そしてなぜ御社のブランドのコンテンツは海外で伸び悩み続けるのか。短く言うと、InstagramとFacebookのアルゴリズムは、誰が投稿に本当に反応するかを見極める精度を上げ続けています。独自性、新しさ、本物のエンゲージメントを評価し、トレンドを追った型どおりのコンテンツはますます見られにくくなっています。海外展開する中国ブランドにとって最も確実なのはソートリーダーシップです。自社カテゴリーにおける専門家としての判断を使って、ターゲット顧客が本当に気にしている質問に答えることです。

最近の2つのニュースが方向を示しています。Social Media Todayによると、Instagram責任者のAdam Mosseri氏は動画シリーズでプラットフォームのランキングの仕組みを説明しました。企業やブランドはクリエイターや一般の人よりはるかに多く投稿するので、ランキングがなければ、フィードは最も頻繁に投稿するアカウントで埋め尽くされてしまうと率直に指摘しています。10月13日には、Social Media Todayが、Facebookが平易な言葉でアルゴリズムを調整する機能を開始したと報じました。Facebookはこれを、本当に対話できるアルゴリズムを実現するものとして打ち出しています。

Instagramのアルゴリズムは実際に何を評価しているのか？

Mosseri氏によると、ランキングは人々がどう反応するかの予測に基づいています。この人は最後まで見るか、友だちにシェアするか。タイミングも重要なので、フィードはおおむね時系列で、新しい投稿ほど多く表示されます。

同氏はいくつかの指針を示しました。オリジナルのコンテンツは転載より優先される。新しいコンテンツほど多く表示される。小規模なクリエイターの公開投稿は、人々の反応を試すためにフォロワー以外にも表示される。そしてモデルの規模が大きくなるにつれ、より多くのシグナルを考慮するようになる。クリエイターへのアドバイスも実践的です。リーチを伸ばしたいなら、再生回数やいいねではなくエンゲージメント率を見ること。トレンドの移り変わりは速いので、新しい方向性はトライアルリールで試すこと。投稿を増やせばヒットの確率は上がるが、燃え尽きないようペースを守ること。

中国ブランドにとって、最も重要なのは1つ目の原則です。抖音（Douyin、中国版TikTok）など国内のプラットフォームでヒットした動画を転載したり、海外の競合のバズった構成を真似したりしても、「オリジナル」の評価はまず得られません。

Facebookではユーザーがアルゴリズムと「話せる」ようになった。ブランドは何に注意すべきか？

Social Media Todayによると、Facebookのユーザーはフィードとリールで、もっと見たいもの・減らしたいものを自分の言葉でアルゴリズムに伝えられるようになり、おすすめは同じセッション内で調整されます。「興味あり」や「興味なし」をタップした後に、Facebookが追加の質問をすることもあります。Facebookは、日常の言葉の背後にある関心、文脈、意図を理解するために大規模言語モデルを使っているとしています。

私たちの見方はこうです。ユーザーが「自宅でのエスプレッソの淹れ方のコツをもっと見せて」とただ言えるようになれば、テーマが明確で本当に役立つコンテンツはマッチしやすくなり、押し売りの広告のように見える投稿は「これは減らして」の一言で締め出されやすくなります。ただし記事は、ほとんどのユーザーは設定をめったに変えないため、この機能が実際にどれだけ使われるかはまだわからないとも注意しています。

なぜトレンドを追うとリーチは増えるどころか減るのか？

行動経済学ではこれを群集効果と呼びます。情報が不完全なとき、人は他人の選択を真似しがちで、みんながやっていることは正しいに違いないと考えます。SNSでの典型的な形はこうです。ある形式がヒットすると、すべてのブランドが同じ音源、同じ冒頭のフック、同じ「本物らしい」台本で押し寄せます。

その結果、コンテンツはますます似通っていきます。ToucHighの競合コンテンツ調査では、SNSコンテンツの約87%が同じ「本物らしさ」の型に押し寄せていることがわかりました。誰もが同じに見えると、アルゴリズムは誰のコンテンツが人の手を止めさせ、最後まで見させ、シェアさせるかを予測しにくくなります。トレンドを追う世界では、本物らしさこそ最も希少な通貨です。これは、ToucHighチームがACM SIGIRで発表したコンテンツの均質化に対抗する査読付き論文で研究したテーマでもあります。

ソートリーダーシップの投稿はどう書くのか？

  1. 本物の疑問や意見の違いから始める。例えば、「今日は新製品をご紹介できることをうれしく思います」ではなく、「ステンレスは絶対にさびないと思っている人は多いです」。
  2. 最初の一文で主張を述べる。海外のユーザーは速くスクロールします。手を止めてほしいなら、主張を先に置く必要があります。
  3. 自社にしかない根拠を示す。工場の試験データ、手直しの記録、カスタマーサービスの統計、創業者自身の経験は、どれも形容詞に勝ります。
  4. トレードオフについて正直に語る。自社の解決策が誰に向いていて、誰に向いていないかを言いましょう。誠実さは完璧さより信頼されます。
  5. 具体的な質問で締めくくる。例えば「フライパンを買うとき、重さと耐久性のどちらを重視しますか？」。中身のない「フォローしてね」では決して生まれない形で、コメントを引き出せます。
  6. 各プラットフォームになじむ形にする。同じアイデアを、Instagramではリールかカルーセルに、LinkedInでは長文のテキスト投稿に、TikTokでは顔出しの短尺動画にします。
  7. トライアルリールで少しずつ試す。新しい方向性はまず小規模に試し、本格的に注力する前にエンゲージメント率を確認しましょう。

米国のオーディエンス向けに書くとき、見落とされがちな細部があります。言語そのものです。中国語から逐語訳した英語は製品マニュアルのように読め、スクロールする手を止めることはまずありません。インチ、ポンド、華氏など、米国人が慣れている単位と言い回しを使いましょう。「best quality」のような空疎な言葉は省き、具体的な使用場面と数字について書きます。投稿が詳しい人の話のように聞こえれば、アルゴリズムもオーディエンスもチャンスを与えてくれます。

どのくらい投稿すべきか、燃え尽きずに試すにはどうすればよいか？

Mosseri氏は、投稿を増やせばヒットの確率は上がると言う一方で、燃え尽きにも注意を促しています。2〜3人の輸出チームにとって現実的なペースは週3〜5回で、そのうち少なくとも半分は上の表のソートリーダーシップにし、残りは製品や販促の投稿で構いません。毎月、エンゲージメント率が最も高かった5本の投稿を選び、そのテーマと冒頭のフックを翌月のひな形にしましょう。

英語での執筆がボトルネックなら、ToucHighのSocial Media Manager Autopilotが役立ちます。ブランドの口調でネイティブ米国英語の投稿を書き、予約投稿の前にそれぞれにエンゲージメント予測スコアを付けます。このスコアはコーパスのパターンに基づく公開前の見積もりであり保証ではありませんが、明らかに平凡な版を公開前にふるい落とすのに役立ちます。

よくある質問

海外のSNSでは、今も投稿時間は重要ですか？

重要ですが、考えすぎないでください。Instagram責任者のAdam Mosseri氏によると、フィードはおおむね時系列で、新しい投稿ほど多く表示されるので、ターゲットのオーディエンスが活発な時間に投稿するのは今も役立ちます。とはいえ、分単位で投稿時間を合わせるより、コンテンツそのものが視聴、シェア、コメントを生むかどうかのほうがはるかに重要です。

中国のプラットフォームでバズった動画を、ブランドのアカウントで転載してもよいですか？

そのままでは避けましょう。Mosseri氏はオリジナルのコンテンツが転載より優先されると述べており、中国のプラットフォームでヒットした動画の文脈、テンポ、ユーモアは、海外のオーディエンスには響かないかもしれません。工程の説明や試験結果など価値のある核の部分は残し、海外プラットフォームのスタイルに合わせて撮り直し、英語のキャプションと文章を添えるのがより良い方法です。

トライアルリールとは何ですか？中国ブランドはどう活用できますか？

トライアルリールはInstagramが提供するテスト機能で、Mosseri氏は新しいコンテンツやアプローチを試すために使うよう勧めています。海外展開するブランドは、異なるフック、テーマ、スタイルを試し、まずエンゲージメント率を確認してから、その方向性を中核のコンテンツにするかを決められます。1回の失敗した実験でアカウント全体の足を引っ張ることなく、プラットフォームの変化についていけます。

ソートリーダーシップは創業者の個人アカウントだけのものですか？

いいえ。ブランドのアカウントでも、ものづくりの知識、テストによる比較、業界の分析など、専門家としての見解を発信できます。違いは、創業者の個人アカウントは立場を表明し個人の経験を語るのに向いており、ブランドのアカウントは体系的な知識コンテンツに向いていることです。両者を組み合わせると最も効果的です。創業者が「なぜ」を説明し、ブランドが「どのように」を見せます。
